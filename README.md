# InfoFeed - Notícias Reais 🌐

O **InfoFeed** é um agregador inteligente de notícias em tempo real projetado para reunir em um único feed as principais atualizações do dia a dia, mercado financeiro, esportes, clima e tecnologia.

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido com uma arquitetura moderna e limpa:
* **HTML5 & CSS3**: Estrutura responsiva e Design System personalizado com suporte a Modo Noturno (*Dark Mode*).
* **JavaScript (Vanilla)**: Consumo de APIs assíncronas e manipulação dinâmica do DOM.
* **Supabase**: Autenticação de utilizadores (Google OAuth) e base de dados em tempo real para o sistema de comentários.
* **Vercel**: Hospedagem em nuvem e automação de deploys contínuos (CI/CD via GitHub).

## ✨ Funcionalidades

* **Feed Dinâmico**: Agregação de notícias globais atualizadas.
* **Barra de Indicadores Económicos e Climáticos**: Cotações de moedas (Dólar, Euro), índices de bolsas (Dow Jones, Nasdaq, Ibovespa) e meteorologia local baseada em geolocalização.
* **Sistema de Comentários Interativo**: Autenticação via Supabase e personalização de apelidos com gravação persistente.
* **Segurança e Privacidade**: Modais institucionais (Quem Somos, Política de Privacidade, Termos de Responsabilidade).
